Barbaross — configuration

1. Connecter GitHub une seule fois

Pour que vos modifications soient publiées sur le site, l'administration doit pouvoir écrire dans le dépôt GitHub. Créez un token d'accès :

  1. Allez sur github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Cliquez Generate new token, donnez-lui un nom (ex : barbaross-admin)
  3. Dans Repository access choisissez Only select repositories puis The-Barbaross
  4. Dans Permissions → Contents mettez Read and write
  5. Générez et copiez le token (il ne s'affiche qu'une fois)

Le token reste dans ce navigateur uniquement, il n'est jamais envoyé ailleurs que vers GitHub.
